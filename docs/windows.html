Рабочее место отчётника

После этой установки у тебя в редакторе Cursor будет Codex: он читает и правит Excel, Word и PDF, сверяет документы с ТЗ и собирает отчёты. Программировать не нужно, с ним говоришь обычными словами.

Рекомендуется Windows 11. Подойдёт обновлённая Windows 10 версии 2004 или новее. Для компьютеров на ARM и 32-битной Windows эта версия установщика не подходит - напиши Дарье.

  1. Поставь Cursor

    Cursor - это окно, в котором будет жить Codex.

    1. Открой cursor.com/download и скачай версию для Windows (x64).
    2. Открой скачанный файл и пройди установку Cursor с обычными настройками.
    3. Запусти Cursor. Если попросит войти, хватит бесплатного аккаунта.

  2. Поставь Codex и войди

    В Cursor открой терминал: меню Terminal → New Terminal (или Ctrl+`). Внизу появится панель с мигающим курсором. Рядом с кнопкой «+» выбери PowerShell или Windows PowerShell. Сам Cursor запускай обычным способом, не «от имени администратора». Вставь туда команду и нажми Enter:

    powershell -ExecutionPolicy Bypass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

    Когда закончится, полностью закрой Cursor через File → Exit и открой снова. Открой новый терминал PowerShell. Для входа выбери авторизацию через устройство (Device Authorization): вставь команду и нажми Enter:

    codex login --device-auth

    Codex покажет адрес страницы и одноразовый код. Открой указанный адрес в браузере, войди в свой аккаунт ChatGPT с доступом к Codex или аккаунт, выданный организацией, и введи код. Дождись сообщения об успешном входе в терминале.

    Если вход через устройство недоступен или непонятно, какой аккаунт использовать, напиши Дарье.

    После успешного входа переходи к следующему пункту в том же терминале.

  3. Запусти установку программ для документов

    В том же терминале вставь команду и нажми Enter:

    powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/dgyshka/mosforum-codex-office/main/bootstrap-codex-office.ps1 | iex"
    • Установщик спросит по-русски, подключить ли управление Google Chrome. 1 - подключить, 2 - пропустить. Это необязательно: для документов браузер не нужен. При согласии Codex будет открывать отдельное окно уже установленного Chrome и работать с сайтами по твоему поручению. Новый браузер не скачивается. В аккаунты сайтов нужно войти самостоятельно. Если Chrome не установлен, этот шаг будет пропущен.
    • Если появится сообщение «Не найден winget», открой Microsoft Store, установи или обнови «Установщик приложений» (App Installer), перезапусти Cursor и повтори команду. Если Store закрыт организацией, напиши Дарье.
    • Windows может спросить, разрешить ли установку программы. Нажми Да. Если потребуется пароль администратора, обратись к тому, кто обслуживает компьютер.
    • Дальше скрипт всё делает сам и печатает, что поставил. В конце он проверит создание документов, формулы Excel и распознавание русского текста.

    В конце будет «Готово: офисные программы проверены, шесть навыков и Superpowers подключены». Если установка остановилась с ошибкой, скопируй сообщение и напиши Дарье. После исправления можно повторить ту же команду.

  4. Начни работать

    1. Закрой Cursor полностью через File → Exit (Файл → Выход). Открой снова, чтобы он увидел новые программы и настройки.
    2. Открой Terminal → New Terminal, выбери PowerShell, набери codex и нажми Enter.
    3. Codex сам начнёт работу в «Отчётах» с офисными настройками. Выбирать папку вручную не нужно. Если сбоку мешает чат Cursor, закрой его крестиком.

    При первом запуске Codex может предложить настроить защиту Windows и запросить подтверждение администратора. Разреши настройку; если прав нет, напиши Дарье.

    Внизу чата видны модель, папка и оставшийся контекст. Звук подскажет, когда ответ готов или требуется подтверждение. Оформление выбираешь сама.

    Напиши Дарье «всё работает».

Как работать с Codex

Для новой работы просто открой терминал PowerShell, набери codex и нажми Enter. После установки он сам начнёт работу в «Документы → Отчёты» с офисными настройками. Выбирать папку каждый раз не нужно. Само открытие терминала чат не запускает.

«Отчёты» - папка для результатов: здесь Codex самостоятельно создаёт и изменяет документы. Исходник можно указать из «Загрузок», готовый файл появится в «Отчётах». Эта настройка действует в PowerShell и Windows PowerShell после перезапуска Cursor. Если «Документы» перенесены в OneDrive, «Отчёты» будут там. В командной строке cmd и в WSL автоматический запуск из этой папки не настроен.

Чтобы вернуться к прежнему разговору, открой терминал и введи codex resume --all. Появится список сохранённых чатов из разных папок. Выбери нужный: Codex откроет его сохранённую историю, и можно будет продолжить разговор.

Команда показывает чаты, доступные в этой установке Codex. Удалённую историю она не восстанавливает. Для продолжения с офисными настройками используй codex --profile mosforum-office resume --all.

Обычный режим - codex. Он подходит для отчётов, таблиц, договоров и презентаций. Codex самостоятельно работает в «Отчётах», а при необходимости выйти за ограничения может попросить разрешение.

Режим без подтверждений - codex --yolo. В нашей установке он тоже открывает «Отчёты» и сохраняет навыки, офисные программы, звуки, строку состояния и подключение Chrome, если оно настроено. Модель и качество работы от этой команды сами по себе не меняются.

Разница в разрешениях: --yolo отключает запросы подтверждения выполнения команд и песочницу Codex. Команды смогут менять файлы вне «Отчётов» и обращаться к сети в пределах прав пользователя и ограничений системы. Правила «не трогай исходник» остаются указаниями агенту, но не технической защитой. Вопросы по содержанию задачи, входы в аккаунты и системные запросы Windows могут оставаться.

Когда это может пригодиться: для заранее понятной длительной обработки, которую не должны останавливать запросы разрешений, предпочтительно на отдельной тестовой машине или в изолированной среде. Например, обработка копий документов в нескольких папках. Обычно достаточно codex и разрешения на конкретное действие. --yolo не нужен, чтобы просто читать Excel, создавать PDF или использовать навыки.

  • Говори обычными словами: какой файл, что с ним сделать, с чем сверить.
  • Файлы из Телеграма и почты лежат в «Загрузках». Codex их найдёт, если назвать файл.
  • Исходник он не перезаписывает: новый вариант сохраняет в «Отчётах» с пометкой «исправлено».
  • Цифры, ФИО и ссылки не выдумывает. Где данных нет, оставит жёлтую ячейку «заполнить».
  • Перед «готово» сам открывает файл и проверяет, что таблица не поехала и формулы считаются.
  • Удаление файлов, отправку наружу и платные сервисы делает только после твоего «да».

Например, так можно начать первый разговор:

В Загрузках лежат ТЗ «Описание объекта закупки» и «МЕДИАПЛАН ОБЩИЙ-4». Сверь медиаплан с ТЗ по пунктам: чего не хватает и что оформлено неверно. Потом собери исправленный медиаплан в папке «Отчёты», исходник не трогай.

Вопросы Codex и установщика будут по-русски. На системных кнопках: Allow / Approve - разрешить, Deny / Reject - отказать, Cancel - отменить. Если смысл непонятен, попроси Codex объяснить по-русски.

Не понятно, что он ответил - напиши «объясни проще». Совсем тупик - скриншот Дарье.
