Рабочее место отчётника

После этой установки у тебя в редакторе Cursor будет Codex: он читает и правит Excel, Word и PDF, сверяет документы с ТЗ и собирает отчёты. Программировать не нужно, с ним говоришь обычными словами.

Macс паролем администратора
~5 ГБсвободного места
30-40 минутпочти всё время ждёшь загрузки

  1. Поставь Cursor

    Cursor - это окно, в котором будет жить Codex.

    1. Открой cursor.com/download и скачай версию для Mac.
    2. Открой скачанный файл и перетащи Cursor в папку «Программы».
    3. Запусти Cursor. Если попросит войти, хватит бесплатного аккаунта.

  2. Поставь Codex и войди

    В Cursor открой терминал: меню Terminal → New Terminal (или Ctrl+`). Внизу появится панель с мигающим курсором. Вставь туда команду и нажми Enter:

    curl -fsSL https://chatgpt.com/codex/install.sh | sh

    Когда закончится, открой новый терминал, набери codex и Enter. Выбери Sign in with ChatGPT («Войти через ChatGPT») и войди в свой аккаунт с доступом к Codex или аккаунт, выданный организацией.

    После входа открой ещё один терминал через Terminal → New Terminal: следующая команда вставляется в обычный терминал, а не в чат Codex.

  3. Запусти установку программ для документов

    В том же терминале вставь команду и нажми Enter:

    curl -fsSL https://raw.githubusercontent.com/dgyshka/mosforum-codex-office/main/bootstrap-codex-office.sh | bash
    • Установщик спросит по-русски, подключить ли управление Google Chrome. 1 - подключить, 2 - пропустить. Это необязательно: для документов браузер не нужен. При согласии Codex будет открывать отдельное окно уже установленного Chrome и работать с сайтами по твоему поручению. Новый браузер не скачивается. В аккаунты сайтов нужно войти самостоятельно. Если Chrome не установлен, этот шаг будет пропущен.
    • Может всплыть окно «Установить инструменты разработчика» - нажми Установить, дождись конца и повтори команду.
    • Когда спросит Password, введи пароль от Mac. Буквы при вводе не видны, так и задумано. Нажми Enter.
    • Дальше скрипт всё делает сам и печатает, что поставил. Самое долгое - LibreOffice, около гигабайта.

    В конце будет «Готово: офисные инструменты проверены, шесть навыков и Superpowers подключены». Если установка остановилась с ошибкой, скопируй её в чат с Codex и напиши «почини», затем повтори команду.

  4. Открой рабочую папку и начни

    1. Закрой Cursor полностью: Cmd+Q. Открой снова, чтобы он увидел новые программы.
    2. File → Open Workspace from File… → Документы → Отчёты → МосФорум.code-workspace. Это рабочее место создал скрипт.
    3. Если Cursor спросит, доверяешь ли ты папке, выбери Yes, I trust the authors («Да, доверяю авторам»). Для автоматического запуска Codex выбери Allow («Разрешить»). Если такого запроса нет: Cmd+Shift+P → Tasks: Manage Automatic Tasks in Folder → Allow Automatic Tasks, затем открой рабочее место заново.
    4. Терминал Codex развернётся. Если сбоку остался чат Cursor, закрой его крестиком. Если Codex не запустился, открой терминал и выполни bash "$HOME/.codex/office/start.sh".

    Внизу чата видны модель, папка и оставшийся контекст. Звук подскажет, когда ответ готов или требуется подтверждение. Оформление выбираешь сама.

    Напиши Дмитрию «всё работает».

Как работать с Codex

  • Говори обычными словами: какой файл, что с ним сделать, с чем сверить.
  • Файлы из Телеграма и почты лежат в «Загрузках». Codex их найдёт, если назвать файл.
  • Исходник он не перезаписывает: новый вариант сохраняет в «Отчётах» с пометкой «исправлено».
  • Цифры, ФИО и ссылки не выдумывает. Где данных нет, оставит жёлтую ячейку «заполнить».
  • Перед «готово» сам открывает файл и проверяет, что таблица не поехала и формулы считаются.
  • Удаление файлов, отправку наружу и платные сервисы делает только после твоего «да».

Например, так можно начать первый разговор:

В Загрузках лежат ТЗ «Описание объекта закупки» и «МЕДИАПЛАН ОБЩИЙ-4». Сверь медиаплан с ТЗ по пунктам: чего не хватает и что оформлено неверно. Потом собери исправленный медиаплан в папке «Отчёты», исходник не трогай.

Вопросы Codex и установщика будут по-русски. На системных кнопках: Allow / Approve - разрешить, Deny / Reject - отказать, Cancel - отменить. Если смысл непонятен, попроси Codex объяснить по-русски.

Не понятно, что он ответил - напиши «объясни проще». Совсем тупик - скриншот Дмитрию.
